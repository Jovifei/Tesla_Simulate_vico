# S12 Engine-Audio Ecosystem Research

Stage W research registry. This is a clean-room evidence index, not a source
code import. Public concepts may inform Track-S experiments; third-party code,
presets, recordings, weights, binaries and proprietary output remain outside
the S12 source tree unless a separate rights receipt says otherwise.

The canonical machine-readable registry is `source_registry.json`; build and
license evidence are separated in `source_build_receipts.json` and
`license_receipts.json`. `R3`, `UNVERIFIED`, `NO_LICENSE_FOUND` and
`PUBLIC_DOCS_ONLY` are evidence boundaries, not qualification states.
