# S12 Engine-Audio Ecosystem Research

状态：`RESEARCH_EVIDENCE_INDEX`

本目录记录外部来源、license/rights、method adoption 与 clean-room 证据，不是第三方源码/媒体仓库。

当前研究分两代：

1. Stage W→Z：发动机 event/path/persistent/source-layer 架构和 method adoption；
2. Stage AD：analysis-by-synthesis、parameter inversion、synthetic↔real domain gap、vehicle-state/realtime separation。

入口：

- `source_registry.json`
- `source_evidence_receipts.json`
- `source_coverage_matrix.json`
- `method_adoption_matrix_v3.json`
- `license_matrix.md`
- `stage_ad_closed_loop_sources.md`

第三方 code、presets、recordings、weights、binaries、commercial outputs 不因“公开可访问”自动进入工程。`R3 / UNVERIFIED / NO_LICENSE_FOUND / PUBLIC_DOCS_ONLY` 是边界，不是 qualification。

当前研究数量已经足够；默认优先把已有方法做成真实闭环和 Android 产品，不为增加 source count 而继续无目标搜仓库。
