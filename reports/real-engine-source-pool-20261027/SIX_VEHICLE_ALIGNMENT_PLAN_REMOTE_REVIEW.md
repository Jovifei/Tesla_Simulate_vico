# 六车型真实声浪对齐路线（2026-10-27）

状态：计划草案；本文件不授权产品源码、默认声库、APK、设备或公网改动。

目标：让 Hellcat、C63 W204、Ferrari 458、Lexus LFA、GT-R R35、Supra JZA80 的声浪在可声明的工况范围内尽量接近真实车辆，同时保留明确的证据边界。不可把软件测试通过、公开录音、合成物理模型或单个车型的听感迁移成 OEM 真实性结论。

## 总路线

`来源池 → 车型身份冻结 → R1/R2/R3 分层 → 状态合同 → 原始/解码收据 → 真实录音特征 → 三路离线对照 → 独立 holdout → 盲听 → 设备/输出回录 → 产品接入 → 六车回归`

每个车型独立通过；总测试数量不能替代单车证据。缺证据时状态必须是 `INSUFFICIENT_EVIDENCE`、`NOT_R1`、`NOT_R2` 或 `NOT_EVALUATED`，不能以零误差或空字段冒充通过。

## 阶段 0：来源和身份冻结

范围：六车逐车建立 source receipt，不改声源。

每条来源记录：精确车型/年款/发动机/排气和改装状态、录音视角与麦位、原始文件和解码文件 SHA-256、采样率/声道/位深、AGC/增益/后处理、许可用途、来源 URL/作者、热状态、工况标签、是否同步 RPM/load/gear/phase、是否独立 take。

分层：

- `R1`：原始媒体、许可、同步 RPM/throttle/load/gear/phase、采集链和多工况均齐全，可进入自动阶次/状态拟合。
- `R2`：可核查来源和受控视听工况，能听到仪表或马力机，但缺完整数字遥测；只用于频谱/包络和人耳目标，不授权自动 RPM 对齐。
- `R3`：公开实录，麦位/AGC/状态不完整；只用于具名视听参考和纹理研究。

退出门：车型身份、许可和文件 SHA 必须齐全；没有独立 holdout 时不得进入声学资格。未经验证的改装、Redeye/Nismo/Tomei/headers/burble 等不得并入普通目标。

停止条件：来源页失效、许可不清、车型身份冲突、原件缺失或把视频标题当状态证据时停止该车型，不降级门槛救活。

## 阶段 1：状态合同和录音入库

复用方案 A 的 `vico.recorded.state-contract.v1` 与 `INSUFFICIENT_EVIDENCE` 逻辑。每车至少覆盖：暖怠速、低/中/高转稳态、带载加速、收油/发动机制动、换挡、启停；有增压车型另记录 boost/bypass/intake 条件；冷启动和热启动分开。

R1 采集优先保留共同时间轴：音频 + RPM + 节气门 + MAP/扭矩/负载 + gear/clutch + 温度 + phase marker。状态 trace 与 PCM 必须可复现同步。独立 holdout 按独立 take 或采集时段划分，不把同一录音切片当训练和测试。

退出门：合同验证通过、训练/留出工况齐全、源和派生 SHA 固定。任一字段缺失则只允许 R2/R3 研究，不进入 coordinated voice。

## 阶段 2：只读特征分析

原始文件不改、不归一化、不自动补增益。输出：1 s/100 ms 能量包络、RMS/峰值/DC、谱质心/带宽、谐波/阶次候选、0.5–10 Hz 调制、粗糙度、端点相关、ACF 和非平稳事件。

无同步 RPM 时，任何阶次只能标为候选；不能用最大谱峰反推实测 RPM。声部分解是表示，不是证明已经拆出真实排气/进气/机械/增压器通道。

退出门：分析结果可复算、原件身份绑定、窗口和参数冻结；无法解释的周期、相消或能量下陷保留为失败诊断。

## 阶段 3：三路离线对照

固定连续轨迹：`15 s idle → 15 s acceleration → 15 s high-rpm → 10 s coast → 5 s idle`，全程不 reset。每车跑三路且身份分开：

1. `RECORDED_PRIMARY`：真实多区域录音，按状态/相位读取；
2. `LEGACY_BANK`：现有 RPM×load bank；
3. `GENERIC_PHYSICS`：明确标记 generic 的 engine-sim/物理机制输出。

保留控制 CSV、源 PCM、pre-DSP/final PCM、manifest、SHA、CPU/内存和所有失败输出。分析 10/20/100 ms 能量、0.5–10 Hz 调制、重复 ACF、频谱、转速阶次跟随、过渡跳变、峰值、削波和实时预算。

硬门：非有限值=0、硬削波=0、固定轨迹无 reset、块分割一致；任何新候选必须留出验证，不得换 seed、每窗 gain 或事后改阈值。

没有 R1 同步状态或 holdout 时，结果可以做研究比较，但不得标记车型资格或产品候选。

## 阶段 4：有限重构与声源选择

仅在阶段 3 通过后，对单车和单一工况做最小有界重构：原速基线、可靠周期/相位连续重排、非周期纹理残差。优先保留真实录音，不用泛化正弦补全缺失工况；缺工况格显示缺失，不外推为全红线。

选择标准：车型身份可听辨、动态/调制自然、无固定慢周期、过渡无相消、与 holdout 不退化、状态变化可解释。合成物理路线只能作为控制/时序或 generic 对照，不能替代真实车型证据。

## 阶段 5：盲听和设备资格

盲听按车型和工况分组，至少分别评价：车型身份、启动、怠速、带载加速、收油/回火、增压/机械声、周期性、低频压力、疲劳感。保留原比例轨和响度匹配轨，不能用逐片段 gain 掩盖错误。

设备门独立执行：固定 APK/Web SHA、输出采样率、系统音量、耳机/扬声器、录音位置和环境；回录实际 PCM，报告 AudioTrack/AudioWorklet 缓冲、欠载、峰值和频响限制。软件通过不等于设备或人耳通过。

停止条件：任意主观维度明显退化、设备回录失真、输出路由不确定或盲听身份低于基线时回退候选，不进入产品。

## 阶段 6：单车产品接入

只接入通过来源、状态、数字、独立 holdout、盲听和设备门的单车。沿现有 `CoordinatedLongTakeVoice`/`MatlabStatefulBankRenderer` 槽位接入，保持旧声库和事件回退；不新建第二套时钟，不绕过许可、phase、owner、epoch 和取消边界。

接入前绑定：源码 commit、manifest、PCM/参数 SHA、车型身份、版本、测试收据。默认 UI 关闭候选直到 owner 明确批准。

## 阶段 7：六车扩展与发布

先 Hellcat 垂直闭环，再按证据完整度逐车扩展。每车拥有独立状态：`SOURCE`、`R1/R2/R3`、`DIGITAL`、`HOLDOUT`、`HUMAN`、`DEVICE`、`PRODUCT`。任何一车失败不抬高其他车型资格。

六车发布前必须：六车源码/资产身份一致、六车实际入口和路由验证、六车独立盲听记录、六车设备回录、无默认声库未审候选混入、账本与生成视图同步。
