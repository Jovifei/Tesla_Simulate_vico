1. 保存源码/配置/产物身份与实际测试、设备、远端审核或人耳记录。
2. 修改唯一账本的日期、当前工作包、里程碑状态、证据、车型矩阵及阻塞。DONE 必须人工复核证据适用版本。
3. 执行 `python scripts/update-project-progress.py` 生成两个视图。
4. 执行 `python scripts/update-project-progress.py --check`；交付前检查不得遗漏。
5. 同批交付代码、证据、账本和文档；不以定时刷新代替真实状态更新。
