# C63高转掉幅与层混音：拒绝结果也必须保留

状态：`REJECTED_OFFLINE_CANDIDATES`。基线955b135；不修改已装normal bank或权威Python S12/reference emitter。

原16个loop均由原recipe逐float32重建。5500→6800RPM、load.92：source RMS下降13.4773dB，bank下降15.8605dB；端点未混RPM层，所以不能把全部掉幅归为相消。另一方面，实际renderer在6950/.32测试中确有额外相消。它们是不同机制，不能用一个gain滑杆遮掉。

两条最小候选均失败：

- 高转四loop按裁剪来源循环轮转，保持各loop频谱/RMS/峰；严重新组合相消中位改善2.47374dB，未达3dB门，另有保护频带退化。没有进入动态或产品资格。
- 新增5400/5600四loop，保持原source/gain，修窄共振采样；1–4kHz目标误差改善10.7–12.6dB，但6100整体RMS误差中位恶化7.84dB，保护门失败。目标频段变好不能代表整声变好。

经验：先分离source端点、传递链、层混音与事件；固定原gain和峰预算，保持失败窗口及已见/新见评估条件的区别。报告源/PCM身份和实际执行链，不能将恒速SoundState→renderer说成REAL控制器或真机验收。没有独立的执行前合同时间锚，就不能声称正式预注册。不能看到某一频段通过便隐藏其他频段、RMS或动态未跑项。

完整数学结果、失败行、复放命令与原始PCM哈希见[研究包](../../review_packages/vico-high-rpm-rejections-20261005/README.md)。研究包不内置失败WAV或私有数据，可在新目录从精确955源重建。两条下一步表示设计只供评审，不擅自更换权威source或normal loader。

这批是失败经验与复放工具落库，没有新增声学修复交付。道路、设备输出和人耳接受均不能由这些数字推定。
