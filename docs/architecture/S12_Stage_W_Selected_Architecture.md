# S12 Stage W Architecture Decision

Decision: **no architecture is selected**.

The executable candidates are P2H (persistent event engine, waveguide and
frozen PTR) and P3 (P2H plus timbre map). Both are kept as reversible,
synthetic Track-S candidates. P1 Legacy and P2 delay/LPF remain comparison
baselines. P5 clean-room synthetic transients are allowed without rights-bound
source material; P4 and any P5 external source material require rights-bound
media. P6 is an offline ENSIM4
teacher and is not a Runtime candidate.

The current Hellcat bake-off proves rendering, equal frame alignment, frozen
PTR output, state traces and afterfire eligibility. It does not contain a
legal, RPM/state-synchronised Reference. Therefore W10 has no valid
multi-reference median improvement, 20% target-improvement or non-target
regression evidence. P2H/P3 are **not selected**, cannot be Profile Frozen and
cannot unlock W11's selected-architecture migration.

The Ferrari/RX-7 package is only preselection readiness evidence. Selection
requires a fresh Reference/Parent/Candidate comparison using post-PTR final PCM
and the predeclared fail-closed gates.
