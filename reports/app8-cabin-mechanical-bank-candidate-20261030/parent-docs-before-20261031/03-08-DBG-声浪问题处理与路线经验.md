# 声浪问题处理与路线经验

**维护状态：持续追加。更新：2026-10-30。** 本记录汇总问题、证据、处理与未通过的方向；具体数值和运行以链接的原始回执为准。2026-10-29 实际仿真记录和 2026-10-30 只读审计属于不同日期的证据。

## 当前结论

- Jovi 已明确拒绝 SR 和 SR2：缺少机械轰鸣、偏电磁、过于光滑。目标声音仍未达到；不能用数字通过覆盖人耳反馈。
- 输入桥和数字时序、压力/PCM 检查边界、运行捕获及试听文件可追溯性已有针对性验证；这些解决的是工程执行问题，不代表声学真实性通过。
- 暂停将现有稀疏声源的少量正弦增益、机械调幅和总谱低频着色微调作为主要改进路线。这不是否定所有谐波合成、滤波或程序化模型；新的机制仍须有目标条件约束、对照与听评。
- 原模型、声库和 Android 保持；新的源码、模型或仿真方案先形成具体范围，再按 Jovi 的要求获得授权。

## 问题与处理记录

### 1. 输入桥未真正消费外部纹理权重，时序末帧越界

- **现象/原因：** 旧接口出现 `MATLAB:minrhs` 和纹理权重约束错误；外部变量不等于模型 Inport 真正接通，旧终点还可能多调用一个帧。
- **处理和验证：** 在先前授权范围修复输入准备和隔离模型的 `SimulationInput.setExternalInput`；核对三层独立权重、零权重等价、非零消费。20 ms 帧从 0 至 89.98 s，共 4500 帧，每帧 960 个 48 kHz 样本。
- **状态：已解决数字接线和帧时序；声学质量另判。** 2026-10-28 MATLAB 110/110、Python 26/26 和真实 90 秒模型运行证据见 [数字接入结果](../../reports/app8-execution-20261028/RESULTS.md)。

### 2. 辐射前压力误用最终 PCM 幅度限制

- **现象/原因：** 旧辅助函数在约 15.04 s 将有限的辐射前数值 1.0103286 按 PCM ±1 范围拒绝；这一节点不是最终归一化音频。
- **处理和验证：** Jovi 专门批准扩围修改该辅助函数：中间量检查形状、实数和有限性，零权重旁路；最终 PCM 的 ±1 门仍严格保留。
- **状态：该边界错误已修复；不能由中间变量名推断实际 Pa。** 见 [数字接入结果](../../reports/app8-execution-20261028/RESULTS.md)。

### 3. MATLAB 仿真目录复用使旧听感批次无效

- **现象/原因：** 旧 runner 的嵌套函数共享 `folder` 变量，导致稳态运行复用输出目录，破坏证据归属。
- **处理和验证：** 保留无效批次标记；把 case 函数改为显式参数的文件级局部函数并拒绝已有输出目录，后续运行采用独立目录与回执。
- **状态：证据归属问题已修复，旧批次不能重新当有效证据。** 原始无效标记见 [INVALIDATED.json](../../worktrees/hellcat-state-contract-20261027/reports/app8-listening-candidate-20261029/runs/full-20261029-011621/INVALIDATED.json)。

### 4. 回归环境缺少 common 路径

- **现象/原因：** 初次回归 127/131；调用环境未包含所需 common 路径。
- **处理和验证：** 明确设置 common 和实验目录后重新执行，131/131；原失败与修正后的记录同时保留。
- **状态：该执行环境问题已修复，不将首次失败抹去。** 见 [失败记录](../../worktrees/hellcat-state-contract-20261027/reports/app8-listening-candidate-20261029/regression.log) 和 [修正后记录](../../worktrees/hellcat-state-contract-20261027/reports/app8-listening-candidate-20261029/regression-bound.log)。

### 5. Frozen 4501 次调用与 4500 帧的差异

- **现象/原因：** 调度回执包含一次 t=0 初始化求值，不能简单认定音频多一帧或误把 20 ms 帧步长说成声学传播延迟。
- **处理和验证：** 短轨追踪初始化；对 8 条长轨全部 4500 帧用同一 Frozen 算法顺序重建，最大误差为 0。8+12 个音频样本延迟在 48 kHz 下约为 0.4167 ms。
- **状态：帧顺序和此初始化解释有证据；同算法复算不是物理正确性验证。** 见 [逐帧验证](../../worktrees/hellcat-state-contract-20261027/reports/app8-rumble-mechanics-candidate-20261029/native-frame-frozen-verification.json)。

### 6. 分析器对合法 JSON 形状和短轨证据形式不兼容

- **现象/原因：** 数学上为整数的维度经 JSON 解码成浮点数时，`numpy.memmap` 不接受；短轨另有直接追踪及顺序核查的证据形式。
- **处理和验证：** 分析器检查数值确实为整数后转换，并识别相应合法证明；保留两份失败日志后重新分析，最终 Python 24/24。
- **状态：分析器兼容性已处理；不能将分析器报错改写成 MATLAB 模型未运行。** 见 [首次分析日志](../../worktrees/hellcat-state-contract-20261027/reports/app8-rumble-mechanics-candidate-20261029/runs/full-20261029-092429-542/analysis-execution.log) 和 [第二次日志](../../worktrees/hellcat-state-contract-20261027/reports/app8-rumble-mechanics-candidate-20261029/runs/full-20261029-092429-542/analysis-execution-2.log)。

### 7. 加速缺少明显换挡变化

- **现象/原因：** 用户指出加速过于平缓且缺换挡听感；旧虚拟工况没有上挡，不能测试上挡过程。
- **处理和验证：** 经单独授权，在虚拟工况中增加 3 次升挡和 1 次降挡，并设置换挡期间燃烧激励减弱及恢复；过程采用启发式状态而非真实变速器仿真。
- **状态：换挡工况已接入并运行；是否像真实换挡仍需听评与匹配实测。** 见 [声学诊断结果](../../reports/app8-acoustic-review-20261028/FINDINGS.md)。

### 8. 压高频和频段占比改善，听感反而更差

- **现象/原因：** Jovi 明确反馈 C 比此前更差、低频和机械感不足。频段变化与人对声音的判断不是同一验收；旧参考也缺匹配转速和负载，部分音频含测试探针。
- **处理和验证：** 保留 C 的拒绝结果及原数字比较；新增同工况、响度匹配、时间结构和声源/辐射链研究。
- **状态：C 人耳拒绝；不能靠降低高频、提升相对低频占比或使用不匹配短录音声称逼真。** 见 [音频研究](../../reports/app8-rumble-mechanics-research-20261029/AUDIO-FINDINGS.md)。

### 9. SR / SR2 实际增加调幅和低频，但用户拒绝

- **现象/原因：** 两档是在现有机械音调上加规则周期包络，并加入 `x + LP220(HP20(x))` 着色；后者增加已有低频成分，并未产生独立的机械冲击或结构声路径。
- **处理和验证：** 2026-10-29 已实际执行 8×90 秒、7 条短轨与 42 条稳态，共 57 份回执；SR/SR2 双次 PCM/WAV 重复，整段响度匹配对照及当时 MATLAB 27/27、Python 24/24。已记录两档人耳拒绝。
- **状态：授权工程试验已完成；声浪目标失败。** 不再将这些 LF/AM 数字当作机械轰鸣通过证据。见 [执行结果](../../reports/app8-rumble-mechanics-research-20261029/EXECUTION-RESULTS.md) 和 [详细路线审计](../../reports/app8-route-audit-20261030/REPORT.md)。

### 10. 源层过于规则，尚无经实测约束的机械激励

- **事实：** 当前多个机械分量为少数阶次的正弦项，燃烧分支为宽周期解析脉冲；identity 分支按帧共同 RMS 归一化，声层电平会相互耦合。SR/SR2 的机械调幅发生在该归一化之后，不能说调幅被归一化抹掉。
- **待验证：** 这些结构与光滑、电磁感相容，但不能把全部听感失败归因给某一个环节；收窄脉冲、关闭归一化或加噪声也都不是已证明的修复。
- **状态：开放的声源机制问题。** 见 [源码路线审计](../../reports/app8-route-audit-20261030/SOURCE-ROUTE-CRITIQUE.md) 及 [燃烧静态形状核查](../../reports/app8-route-audit-20261030/evidence/static-combustion-shape-check.json)；静态公式结果不是实测 PCM 或主观听评。

### 11. bank 过早合流与辐射单位未闭合

- **事实：** 两 bank 在后级之前合成 mono，最终左右复制；没有已建立的独立 bank 管路、汇合、结构声及听音点传播。Frozen 有固定延迟、损耗和两状态递推，源码明确不是完整 FVM/PTR 网络。现有输入未形成可核查的真实压力/体积流量到接收点声压的量纲链。
- **待验证：** 数字路径低频衰减可以计算，但不能仅凭该曲线认定真实物理有误，或直接设计逆滤波作为本车解法。不能把合成中间量叫作已标定 Pa 或实车 SPL。
- **状态：开放的模型与标定问题。** 见 [实际仿真取证](../../reports/app8-route-audit-20261030/SIMULATION-FORENSICS.md) 和 [详细路线审计](../../reports/app8-route-audit-20261030/REPORT.md)。

- **处理和验证：** 保留不可发送记录，不更改项目绑定、不自动重试；本地账本及文档独立记录实际状态。
- **状态：Hub 同步开放，不能宣称发送成功。** 见[独立树不可发送记录](../../reports/app8-route-audit-20261030/hub-NOT-SENDABLE.json)和[根目录连接拒绝记录](../../reports/app8-route-audit-20261030/hub-root-NOT-SENDABLE.json)。

### 13. 新研究：混合声层不能直接作为两条排气管

- **现象/原因：** 2026-10-30 继续查到，现有两列在合流前已包含燃烧、机械、进气等混合层；identity 的机械项还会进入共同归一化分母。直接将两列接双管并称为“真实双 bank 排气”会混淆声源，归一化后简单相减也不能消除分母耦合。
- **处理与证据：** 完成只读接口研究及远端修订方案：在私有副本中分别暴露合成 combustion 与独立机械路径，采用共同声路做单因素消融；用户确认以车内扬声器混合声为目标。参考音频按车型/工况/位置/许可分级，一份商用录音的算法开发用途受到许可限制。
- **状态：方案待 Jovi 授权，尚无新代码、新音频或新仿真；候选机制和参数均未标定。** 新机械路径可避免既有 Frozen 衰减，但最低模态 160 Hz，无法预先保证 50–80 Hz 轰鸣。见[授权方案](../../reports/app8-mechanical-bank-research-20261030/C2C-APPROVAL-PLAN.md)、[本地研究](../../reports/app8-mechanical-bank-research-20261030/LOCAL-FINDINGS.md)和[参考候选与许可](../../reports/app8-mechanical-bank-research-20261030/REFERENCE-SHORTLIST.md)。

### 14. 隔离实验被 MATLAB 启动环境阻塞

- **现象：** GPT-6.1 Terra max 子代理已写入隔离私有 source/identity、事件/模态和双 bank 草稿；函数级测试在原有 MATLAB MCP 会话报告 5/5 与 4/4。独立 R2026a `-batch` 测试随后以 `0xc0000005` 在 MATLAB homesessionmanager/recent-artifacts/threadpool 栈崩溃；一次独立 `-nojvm -batch` 最小 `2+2` 也未打印首条语句即崩溃。
- **处理：** 按停止合同保留诊断命令、退出码、两个 crash dump 和独立 prefs；没有创建新 SLX，没有编译、短仿真、90 秒长轨、PCM/WAV 或车内等响试听。隔离目录外 7,942 个文件、9,129,302,830 字节初末 SHA/大小一致。
- **状态：** 私有函数仍是未完成研究草稿；数字/声学/设备/人耳资格均未提升。恢复并独立验证 MATLAB 启动后，才可重新评估是否继续；不得把函数级测试或启动诊断写成 Simulink 通过。见[执行状态](../../worktrees/hellcat-state-contract-20261027/reports/app8-cabin-mechanical-bank-candidate-20261030/EXECUTION-STATUS.md)和[保护完整性](../../worktrees/hellcat-state-contract-20261027/reports/app8-cabin-mechanical-bank-candidate-20261030/protected-integrity.json)。

## 下次研究和验收顺序

1. 先明确目标听音位置和能让 Jovi 认可的参考；尽量记录转速、负载、挡位、采集链及素材使用条件，未知条件素材只作风格参考。
2. 研究三种候选方向：匹配工况的分析/重合成标杆；事件激励与有记忆的结构响应；按缸/阀事件驱动的双 bank 排气传播，并独立处理结构声。它们是待对照的假说，不是现成授权或真实性证明。
3. 对每条机制先做可归因的小范围同输入、同响度消融，保留时域、阶次和听评；获认可后再冻结参数做 90 秒和独立工况验证。真实录音的接收域信号不得无定义地再次经过未知声路。
4. 保留既有帧时序、原生捕获、哈希、回归和响度匹配基础，区分源码、历史仿真、真实设备与人耳证据。
